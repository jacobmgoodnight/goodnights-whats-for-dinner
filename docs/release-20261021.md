## Database release record

Before changes, privately captured all seven `gw_*` tables and their deployed schema in one snapshot. The compressed AES-256 PGP backup is under `%LOCALAPPDATA%/Goodnights/release-backups/2026-10-20`, outside the repository and OneDrive. Its encryption key is protected with Windows CurrentUser DPAPI. Local decryption verified the checksum, byte length, schema and all seven data arrays; no production rows were restored or used as test fixtures. Retain both the backup and protected key with the same Windows profile. This is an app-data/schema snapshot, not a full Supabase system/role backup.

Read-only preflight found zero conflicting OSM identity groups, zero conflicting manual name/address groups and zero malformed legacy OSM identities. Inspected the actual deployed RPCs, indexes, constraints, grants and RLS. Reconstructed that catalog in isolated PostgreSQL 17.10/UTF-8 before applying the approved migrations to production PostgreSQL 17.11.

Applied through Supabase's migration API, in this order, before frontend merges:

The migration API assigns application timestamps; these checked-in SQL files are the already-applied sources. **Do not blindly run `db push`, rerun these files, or rerun `database.sql`.** H1 was transaction-wrapped with a schema-cache notification; H4 retained its transaction. Short lock timeouts guarded the production release. Both completed successfully. No data cleanup, merge, delete or rewrite occurred.

All seven production table counts and complete row fingerprints were identical before/after both migrations, covering family/member credentials, restaurant IDs/metadata, poll settings/group credentials/saved ties, rosters, options and ballots. Verified the identity indexes, address trigger, RLS, private helper grants and disabled name-only voting. Live PostgREST resolved both migrated RPCs and the legacy add signature; deliberately invalid credentials were rejected before writing.

Security advisors retain the seven intentional RLS-with-no-policy info findings and existing token-guarded SECURITY DEFINER RPC warnings.
