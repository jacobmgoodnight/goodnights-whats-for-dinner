# Mobile acceptance checklist

Run in a synthetic staging instance or isolated local demo. Record date, commit, device/OS/browser, Safari versus installed mode, outcome and evidence without private links. Chromium viewport emulation is not physical-device testing.

| Journey | Check |
| --- | --- |
| First invitation | Open group invitation in iPhone Safari, installed iPhone app and Android Chrome; choose own name, understand privacy disclosure, submit once. Locked names cannot vote twice. |
| Return | Reopen on the same phone and a later poll; correct remembered person, Not you, saved acknowledgement. A personal link can edit before completion. Invalid links/network failure preserve saved credentials. |
| Organizer | Save organizer link; create a poll with 2–20 places and current people; backtrack through all four steps; preset/repeat drafts stay editable and create nothing until confirmation. |
| All methods | Approval 1–2; consensus yes/no for every place; names-only native Top 3 menus with no reopen/refocus. Scrolling/drift/multitouch must never cast a swipe. |
| Finish | Last-voter arrival and early closure, positive ties/runoff/immutable draw, all-no calm recovery and empty result. Public share strips private credentials and identities. |
| Library | Manual/OSM/Maps paste save, duplicate and separate-location review, archive/restore, coordinate clearing after address edit, failed image SVG fallback, failed search keeps typed input. |
| Connectivity | Airplane mode during save/status refresh, explicit retry, no false saved acknowledgement or duplicate creation. Return after resume/background and a paused database. |
| Accessibility | VoiceOver/TalkBack labels and reading order; hardware keyboard/visible focus; native date and ranking controls; OS large text/200%, reduced motion, contrast and touch target usability. |
| Layout | 320px to large phones, portrait/landscape, software keyboard open, bottom safe area, scrolling/sticky actions, no obscured submit or horizontal overflow. |
| Installation | Credential-free Home Screen start; identity on installed origin; no offline-voting promise or automatic permission prompt. Optional alerts enable/deny/disable only on explicit taps; real receipt is a separate opt-in staging check. |
| Dinner decisions | Quick Pick without a poll, cuisine/no matches, alternatives exhausted/restart, explanation; record a meal explicitly from result or library, local date, edit/delete, reload and second-device consistency. Run after the meal migration is approved. |

Automated Node and intercepted browser checks cover many invariants. None establishes Safari native sheets, physical touch, real OS keyboards, assistive technology, multi-phone synchronization or push receipt. Those remain release sign-off items.
